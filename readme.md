# ✨ Neova

> **Go from package idea to a build-ready Node.js project in one command.** 🚀

Neova is an interactive scaffolder for Node.js package builders. Choose
JavaScript or TypeScript, pick ESM, CommonJS, or both, and get a clean project
starter ready for your ideas. Spend less time on setup and more time building
the package you can't wait to share. 💡

## ⚡ Get started

Ready to create? Run:

```bash
npx neova
```

Or always use the latest release:

```bash
npx neova@latest
```

## 🎛️ Make it yours

Follow the interactive prompts to name your package and choose your setup:

- 🟨 **Language:** JavaScript or TypeScript
- 📦 **Module format:** ESM, CommonJS, or Dual (ESM + CJS)

Your new package folder will be created right where you run Neova. Then install
dependencies and build:

```bash
cd <package-name>
npm install
npm run build
```

## 🛠️ Run from a Neova checkout

```bash
npm install
npm run dev
```

**Your next Node.js package starts here.** 🌱
